<objective>
Add a compact **`instruction_lines`** editor (similar add/remove UX to **`FewShotExamplesSection`** but tighter `maxLength` and smaller **`minHeight`**), shorten the topic textarea height, and send **`instruction_lines`** only when non-empty alongside existing generate quiz payload.

- **XSS**: React escapes textarea values by default; no **`dangerouslySetInnerHTML`**.
- **Privacy**: Instructions leave the browser same as topic — HTTPS assumed in deploy docs.
</threat_model>
