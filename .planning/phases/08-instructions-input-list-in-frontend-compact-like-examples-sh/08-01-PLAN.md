<objective>
Accept optional **`instruction_lines`** on **`GenerateQuizRequest`**, normalize with strict caps, and merge normalized lines **into** the same system-prompt **`instructions`** string passed to **`_system_prompt()`** so they sit alongside `_question_class.instructions`, before the few-shot appendix.
</objective>

<threat_model>
### Threats & mitigations
- **Prompt injection**: User text is appended only inside the trusted system prompt template; never executed. Keep JSON output contract unchanged (`outline()` still enforced).
- **DoS via large payloads**: Caps on count and length per line; mirror validation in router with **422**.
</threat_model>
