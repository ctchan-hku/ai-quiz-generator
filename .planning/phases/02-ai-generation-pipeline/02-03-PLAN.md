<action>
Create `backend/app/routers/generate.py` with:

1. A `GenerateTextRequest` Pydantic model:
   ```python
   class GenerateTextRequest(BaseModel):
       topic: str = Field(..., min_length=1, max_length=2000)
       num_questions: int = Field(10, ge=1, le=50)
       model: str
   ```

2. A `limiter = Limiter(key_func=get_remote_address)` at module level.

3. A `router = APIRouter(prefix="/api")`.

4. A `POST /generate/text` endpoint:
   ```python
   @router.post("/generate/text", response_model=QuizResponse)
   @limiter.limit("3/hour")
   async def generate_text(
       request: Request,
       body: GenerateTextRequest,
       client: Annotated[AsyncOpenAI, Depends(get_llm_client)],
   ) -> QuizResponse:
   ```
   
   Inside the handler:
   - Validate `body.model` is in `settings.available_model_ids`; if not, raise `HTTPException(status_code=422, detail=f"Model '{body.model}' is not available. Valid models: {sorted(settings.available_model_ids)}")`
   - Call `raw, messages = await generate_quiz(body.topic, body.num_questions, body.model, client)`
   - Call `schema = await parse_with_retry(raw, client, body.model, messages)`
   - Return `QuizResponse(questions=schema.questions, model_used=body.model, source="topic")`

5. The `@limiter.limit("3/hour")` decorator requires `Request` as the first parameter (slowapi inspects it for IP extraction). Keep `request: Request` as the first non-self parameter — this is mandatory for slowapi to work.
</action>

   ```python

       )
   ```
