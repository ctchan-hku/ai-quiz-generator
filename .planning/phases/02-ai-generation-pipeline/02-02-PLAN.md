<action>
Create `backend/app/services/parser.py` with:

1. A `_strip_fences(text: str) -> str` helper that strips leading/trailing markdown code fences (` ```json`, ` ``` `) from the LLM response before parsing.

2. A `_parse(raw: str) -> QuizSchema` function that:
   - Calls `_strip_fences(raw)`
   - Calls `json.loads(stripped)` — raises `json.JSONDecodeError` on bad JSON
   - The parsed result may be a list (raw array) or a dict with a "questions" key — handle both:
     - If result is a `list`: wrap as `{"questions": result}` before Pydantic
     - If result is a `dict` with a "questions" key: pass directly
     - Otherwise: raise `ValueError("Unexpected LLM output shape")`
   - Validates with `QuizSchema.model_validate(data)` — raises `ValidationError` on schema mismatch
   - Returns the validated `QuizSchema`

3. An `async def parse_with_retry(raw: str, client: AsyncOpenAI, model: str, messages: list) -> QuizSchema` function that:
   - Tries `_parse(raw)` and returns immediately on success
   - On `json.JSONDecodeError` or `pydantic.ValidationError`:
     - Builds corrective messages: original `messages` + assistant reply (`raw`) + user correction request: `"That response was invalid JSON or failed schema validation. Return ONLY the corrected JSON array, no other text."`
     - Calls `client.chat.completions.create(model=model, messages=corrective_messages, response_format={"type": "json_object"}, temperature=0.7, max_tokens=4096)`
     - Tries `_parse(retry_raw)` and returns on success
     - On second failure: raises `HTTPException(status_code=502, detail="LLM returned invalid quiz data after retry")`
</action>
