<task type="auto">
  <name>Task 3: Build State Machine Hook</name>
  <files>src/hooks/useQuizMachine.ts</files>
  <action>
    Implement `useQuizMachine` using `useReducer` and TanStack Query's `useMutation`.
    - State interface: `{ status: 'idle' | 'generating' | 'reviewing' | 'exporting' | 'error', formConfig: { topic, numQuestions, model }, quiz: QuizResponse | null, error: string | null }`.
    - Actions: `START_GENERATE` (sets status to generating and updates formConfig), `GENERATE_SUCCESS` (sets quiz and status to reviewing), `GENERATE_ERROR` (sets error).
    - Explicitly import and call `generateQuiz` from `src/lib/api.ts` inside the `useMutation` setup.
    - Expose the state and the `useMutation` triggers so UI components can dispatch actions and react to state changes.
  </action>
