<objective>
Expose **stable pricing fields** on **`GET /api/models`** for every configured model **without** breaking existing **`id`/`label`** consumers. Normalize **`AVAILABLE_MODELS`** JSON so optional Poe-style **`price.prompt`/`price.completion`** (USD **per token**) OR nested **`price: {input, output}`** (USD **per 1M tokens**) both collapse to **`price: {"input": float|null, "output": float|null}`** in API output (**USD per 1M tokens**).

**MOD-03** satisfied when docs + tests prove shape; **MOD-04** when allowlist source remains **`settings.available_models`** post-normalization.
</objective>

<threat_model>
ASVS L1: `/models` returns only deploy-configured catalog metadata — no API keys, no user content. Avoid executing external network calls in normalization (pure JSON transforms).
</threat_model>

<task type="execute">
<objective>
Add **`normalize_model_entry(raw: dict[str, Any]) -> dict[str, Any]`** with deterministic rules.
</objective>
<read_first>
- backend/app/config.py — **`_FALLBACK_MODELS`**, **`available_models` property**
- backend/scripts/fetch_poe_ai_models.py — **`token_usd_per_m`**, **`model_row`**
</read_first>
<action>
Create **`backend/app/helpers/model_catalog.py`** implementing:

1. Input dict always contains **`id`** (str) and **`label`** (str); if **`label`** missing, copy **`id`**.

2. Output dict preserves **`id`**, **`label`**, and sets **`price`** key to **`{"input": float | None, "output": float | None}`**:
   - If raw already has **`price.input`/`price.output`** numeric → cast **`float`**, allow **`null`** explicit JSON **`None`**.
   - Else if raw has Poe **`pricing.prompt`/`pricing.completion`** strings → convert via **`float(str(v))*1_000_000`** rounded **10** decimals like **`token_usd_per_m`** (reuse logic by importing utility split **OR** duplicate minimal 5-line function — prefer single helper **`usd_per_m_from_token_price(obj) -> float | None`** inside **`model_catalog.py`** to avoid importing scripts package).

3. If neither pricing variant present → **`price`: `{"input": None, "output": None}`**.

4. Strip unknown extra keys from API output **optional** — **keep forward-compat**: forward extra keys **excluding** secrets if any — simplest **do not strip** unless tests demand minimal schema; CONTEXT locks **`price`** shape only.

5. Unit tests **`backend/tests/test_model_catalog.py`**:
   - Fixture **`{"id":"x","label":"X","price":{"input":1.0,"output":2.0}}`** normalizes identical **`price`** numbers.
   - Fixture with **`pricing.prompt":"0.000001"`** yields **`input`** approx **`1.0`** (**float tolerance `pytest.approx`**).

Concrete assertion example: **`assert out["price"]["input"] == pytest.approx(1.0)`**.
</action>

</task>
