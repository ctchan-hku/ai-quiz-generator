<objective>
Return **`cost_usd`** on successful **`POST /api/generate/quiz`** (`QuizResponse`) and **`POST /api/generate/question`** (**wrapper** around **`MultipleChoiceQuestion`** per CONTEXT). Accumulate tokens across **`parse_llm_with_retry`** corrective completions using SDK **`usage`**.

Depends on **`10-01`**: **`normalize_model_entry`** / **`available_models`** exposes **`price.input`/`price.output`** for calculators reading **`settings.available_models`**.
</objective>

<threat_model>
Costs derive strictly from usage counters providers expose plus locally-configured rates — never multiply arbitrary floats supplied by clients.
</threat_model>

<tasks>

<task type="execute">
<objective>
Centralize **`estimate_usage_cost_usd(model_id: str, prompt_tokens: int, completion_tokens: int, catalog: list[dict]) -> float`** (exact placement **`backend/app/helpers/model_catalog.py`** alongside **`normalize_model_entry`** or sibling **`pricing.py`** if clearer — stick single cohesive **`model_catalog`** module unless >350 LOC pushes split).

Formula **`cost_usd = (prompt_tokens/1e6)*p_in + (completion_tokens/1e6)*p_out`** where **`p_in`/`p_out`** resolved by **`next((m["price"]["input"], m["price"]["output"]), lookup)**`; **`None`/`missing`** contributes multiply-as-zero (**replace **`None`** with **`0.0`** multiplier**, NOT **`math.nan`**). Clamp **`prompt_tokens`/`completion_tokens`** ≥ **0** before arithmetic using **`max(0, int(...))`**.
</objective>

- backend/app/helpers/model_catalog.py (created wave **1**)
- backend/app/config.py — **`available_models`**
</read_first>

Exact assertion **`assert estimate_usage_cost_usd(...) == 2.0`** appears for scenario **1**.

<task type="execute">
<objective>
Capture **`usage`** from **`chat.completions.create`** responses.
</objective>
<read_first>
- backend/app/services/llm/openai/client.py — **`complete_chat`**
- backend/app/services/parser.py — **`parse_llm_with_retry`** inner **`retry = await client.chat.completions.create`**
</read_first>
<action>
1. Define **`TokenUsage`** pydantic model **`backend/app/models/usage.py`** (`prompt_tokens: int = 0`, `completion_tokens: int = 0`) plus **`def add_usage(a: TokenUsage, response_usage: object | None) -> TokenUsage`** extracting **`prompt_tokens`/`completion_tokens`** via **`getattr`** guards.

2. Change **`complete_chat`** signature to **`-> tuple[str, list, TokenUsage]`** returning **`TokenUsage`** from **`response.usage`** first completion.

3. Change **`parse_llm_with_retry`** signature to **`-> tuple[T, TokenUsage]`**: initial parse success → **`TokenUsage()`** zeros; recoverable failure path adds **`usage_initial`** if accessible (**requires threading usage out** — refactor so **`parse_llm_with_retry`** accepts optional **`initial_usage: TokenUsage`** argument OR caller passes **`usage_from_first_call`** explicitly).

Concrete orchestration:
- **`FullQuizLlm.generate`** becomes **`async def generate(...) -> tuple[str, list, TokenUsage]`** calling **`complete_chat`** then returning third tuple element.
- **`parse_with_retry`** gains **`*, initial_usage: TokenUsage`** forwarded into **`parse_llm_with_retry`** so corrective completion **`retry.usage`** merges via **`add_usage`**.

Implement **`parse_llm_with_retry`** body:
```
total = initial_usage
try:
    return parse(raw), total
except recoverable:
    ...
    retry = await client.chat.completions.create(...)
    total = add_usage(total, getattr(retry, "usage", None))
    return parse(retry_raw), total
```

Ensure **`HTTPException 502`** path still raises without leaking partial usage beyond logs.

4. Update **`SingleMcqLlm`** mirror **`FullQuizLlm`** adjustments identical pattern.

5. Adjust ALL compile-time references imports (`backend/app/services/llm/__init__.py` only if exports affected — grep **`generate(`** across **`backend/`**).
</action>
