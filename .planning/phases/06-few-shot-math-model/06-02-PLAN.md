Inside a **`<details>`** summary (e.g. “Example / style hints”):

- Hold `exampleRows: string[]` in component state; **initial value `[]`** (no textareas on first paint).
- **Add example** button: append `""` to `exampleRows` if `exampleRows.length < FEW_SHOT_MAX_COUNT`; otherwise disabled or not shown with helper text.
- For each index, render a `<textarea>` (`maxLength={FEW_SHOT_MAX_LENGTH}`, `className="input"`, sensible `minHeight`) and a **Remove** button that splices out that index.
- On submit (`handleSubmit`): after existing topic/model validation, normalize rows (trim, filter empty). If more than `FEW_SHOT_MAX_COUNT` non-empty (should be impossible if UI caps rows — still guard), set local error. If any trimmed value length > `FEW_SHOT_MAX_LENGTH`, set local error.

Build `QuizFormConfig`:

- Always `topic`, `numQuestions`, `model`.
- If normalized examples length > 0, set `few_shot_examples` to that list; otherwise omit `few_shot_examples` from the object passed to `onSubmit`.

Match existing button classes (`btn-primary`, `btn-secondary`) and accessibility (labels, `aria-label` on icon-only buttons if used).
</action>
