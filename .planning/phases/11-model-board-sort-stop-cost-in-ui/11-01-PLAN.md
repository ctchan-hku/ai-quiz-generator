<objective>
Replace the legacy HTML **select** in **`ModelField`** with a **price-aware model board** fed by **`GET /api/models`** (already via **`listModels`** / **`useQuery`** in **`App.tsx`**). Extend **`ModelInfo`** with **`price`**: **`{ input: number \| null; output: number \| null }`** (USD **per 1M tokens**) per Phase **10** contract. Users **sort** by a single comparable price scalar **asc** / **desc** with deterministic tie-breakers; selection stays **controlled** via existing **`pickedModel`** + **`resolvedModel`** so **`POST`** bodies never use a stale **`model`** (**`QuizForm`** still submits **`config.model`** aligned with **`resolvedModel`**).

**SKIPPED:** UI-SPEC — layout and wording follow **`.planning/REQUIREMENTS.md`** §FE-MB-* and **`.planning/phases/11-model-board-sort-stop-cost-in-ui/11-RESEARCH.md`** (§§3–5, 8).
</objective>

<threat_model>
ASVS L1 (UI only): **No secrets** in the client beyond public env (`VITE_API_BASE_URL`). **Do not log** bearer tokens or request bodies containing sensitive data — this feature uses existing anonymous flows only. Prices and labels come from **`/api/models`** as **plain text**: render via normal React children / **`{"text"}`** — **never** `dangerouslySetInnerHTML`.
</threat_model>

<action>
Add **`frontend/src/components/QuizForm/ModelBoard.tsx`** exporting **`ModelBoard`** (replace **`ModelField`** usage rather than layering both).

Props (match / extend **`ModelField`** needs): **`model: string`** (controlled selected **`id`** — always **`resolvedModel`** from **`App`**), **`onModelChange: (id: string \| null) => void`**, **`models: ModelInfo[]`**, **`modelsLoading`**, **`modelsError`**, **`isLoading`** (generation pending — disables picks).

Implementation details (**name these symbols**):

1. **`type ModelSortDirection = 'price_asc' | 'price_desc'`** — local **`useState`** inside **`ModelBoard`**.

2. **`function priceSortKey(m: ModelInfo): number`** — scalar for comparison  
   **`normalizedInput`** = **`m.price?.input ?? Number.POSITIVE_INFINITY`**  
   **`normalizedOutput`** = **`m.price?.output ?? Number.POSITIVE_INFINITY`**  
   **`return normalizedInput + normalizedOutput`** (unknown prices sort **last** in asc mode).

3. **`function sortedModels(models: ModelInfo[], direction: ModelSortDirection): ModelInfo[]`** — copy **`[...models]`**, **`.sort`**, comparator: primary by **`priceSortKey`** (asc flip for desc via direction), tie **`localeCompare`** on **`label`**, then **`id`**.

4. **`useMemo(() => sortedModels(models, sortDirection), [models, sortDirection])`**.

5. Display strings (examples — implement as helpers or inline): **`$…/M input`**, **`$…/M output`** from numeric values; when both **`input`** and **`output`** are **`null`** (or row missing **`price`**), show a short **`Pricing unavailable`** phrase (literal substring acceptable).

6. Sort UI: two **`type="button"`** controls labelled for screen readers — e.g. visible text **`Price: Low to high`** / **`Price: High to low`** toggling **`sortDirection`**; **`aria-pressed`** on the active toggle.

7. Selection: **`input type="radio"`** **`name="quiz-model-choice"`** **`value={m.id}`** per card **`checked={model === m.id}`**, **`onChange`** → **`onModelChange(m.id)`**; **`aria-labelledby`** per card tying **`label`** text to radios.

Keep **`modelsError`** branch with **`role="alert"`** and copy pattern **"Could not load models:"** consistent with **`ModelField`** today.
</action>
