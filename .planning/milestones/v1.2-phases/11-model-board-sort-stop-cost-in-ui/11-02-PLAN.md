<objective>
**Abort (**FE-GEN-01):** Extend **`generateQuiz`** and **`generateQuestion`** in **`frontend/src/lib/api.ts`** to forward **`AbortSignal`** into **`axios`**: **`api.post(..., { signal })`**. In **`useQuizMachine`**, create per-lane **`AbortController`** instances held in **`useRef`** (**`quizAbortControllerRef`** and **`refineAbortControllerRef`** — separate controllers so **`Stop`** on one lane does not cancel the other). Call **`mutationFn`** with that signal — implement by wrapping **`mutationFn`** to call **`generateQuiz(config, signal)`** / **`generateQuestion(body, signal)`**.

On **`Stop`**: **`quizAbortControllerRef.current?.abort()`** (full quiz) or **`refineAbortControllerRef.current?.abort()`** (refinement). Add **`GENERATE_ABORTED`** to **`QuizMachineAction`** in **`frontend/src/types/quiz-machine.ts`**. In **`quizReducer`** inside **`frontend/src/hooks/useQuizMachine.ts`**, handle **`GENERATE_ABORTED`**: when **`status === 'generating'`**, set **`status`** to **`reviewing`** if **`baseQuizResponse != null`** else **`idle`**, **`error: null`**; preserve **`quiz`**, **`questionVersions`**, **`baseQuizResponse`** unchanged. **`generateMutation.onError`**: detect axios cancel (**`import { isAxiosError, CanceledError }`** from **`axios`** or **`error.code === 'ERR_CANCELED'`**) → **`dispatch({ type: 'GENERATE_ABORTED' })`** + **`generateMutation.reset()`** as needed instead of **`GENERATE_ERROR`**. **`refineMutation.onError`**: cancel → **`refineMutation.reset()`** without surfacing **`refineErrorMessage`**.

**Cost (**FE-COST-01**, **FE-COST-02):** Add **`formatEstimatedCostUsd(cost_usd: number): string`** in **`frontend/src/lib/format-cost-usd.ts`** (**`Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD', minimumFractionDigits: 2, maximumFractionDigits: 4 })`**).

**Display:** **`QuizDisplay`** header **`Model:`** line (currently around line **76** showing **`quiz.model_used`**) also shows estimated cost sourced from **`quiz.cost_usd`**.

**Summary / export:** Extend **`buildQuizClipboardText`** so the **`Model:`** line reads **`Model: … · Cost (est.): … · Source:`** (literal substrings **`Cost (est.)`** and **` · Source:`** grep-verifiable). **`QuizExportRecord`** gains **`cost_usd: number`**. Bump **`EXPORT_JOURNAL_SCHEMA_VERSION`** from **`1`** to **`2`** in **`frontend/src/types/export-journal.ts`** and update **`loadJournal`** strict check to **`o.schema_version === 2`** only (**`frontend/src/lib/quiz-export/journal.ts`**). **`buildQuizExportRecord`** copies **`cost_usd: quiz.cost_usd`**. **`JournalSidebar`** expanded **`Model:`** row appends **`formatEstimatedCostUsd(q.cost_usd)`** (**same helper**).

**SKIPPED:** UI-SPEC — follow **`.planning/REQUIREMENTS.md`** (**FE-GEN-01**, **FE-COST-***), **`11-RESEARCH.md`** §§6–7.
</objective>

<action>

1. **`QuizMachineAction`**: add **`{ type: 'GENERATE_ABORTED' }`** (payload-free).

2. **`quizReducer`** (**inside `frontend/src/hooks/useQuizMachine.ts`**): **`case 'GENERATE_ABORTED'`** — rewinds **`generating`** to **`reviewing`** when **`state.baseQuizResponse != null`** else **`idle`**, sets **`error: null`**, preserves **`quiz`/`questionVersions`/`baseQuizResponse`**; if **`status !== 'generating'`**, return **`state`** unchanged.

3. **`useQuizMachine`**:
   - **`quizAbortControllerRef`** and **`refineAbortControllerRef`**: **`useRef&lt;AbortController | null&gt;(null)`** each.
   - Before **`generateMutation.mutate`**: **`quizAbortControllerRef.current?.abort()`** (optional supersede), **`quizAbortControllerRef.current = new AbortController()`**, pass **`quizAbortControllerRef.current.signal`** into **`generateQuiz`**.
   - Pattern: **`mutationFn: (vars) => generateQuiz(vars, quizAbortControllerRef.current!.signal)`** only after assigning controller (**non-null assertion** guarded by **`new`** assignment same tick).

   **`mutate(variables, { signal: quizAbortControllerRef.current.signal })`** **if** you prefer TanStack-managed composite abort — choose **one** approach (explicit **`generateQuiz`** arg is authoritative for Axios).

   - **`generateMutation`** **`onError`**: **`const isCanceled = isAxiosError(err) && (err.code === 'ERR_CANCELED' || err instanceof CanceledError)`** (adjust import list from **`axios`**). If **`isCanceled`** → **`dispatch({ type: 'GENERATE_ABORTED' })`**; **`else`** **`GENERATE_ERROR`**. **`generateMutation.reset()`** after aborted branch if **`isPending` sticks** wrongly.

   - **`refineQuestion`**: new **`AbortController`** per **`mutate`** for **`generateQuestion(..., signal)`**; **`onError`** mirroring cancel skips **`refineErrorMessage`** (**`reset()`** only).

   - Export **`cancelGenerate`** (**`() => quizAbortControllerRef.current?.abort()`**) and **`cancelRefine`** (**`() => refineAbortControllerRef.current?.abort()`**) from the hook **return object**.

Symbolic names **`GENERATE_ABORTED`**, **`cancelGenerate`**, **`cancelRefine`** must appear in source.

</action>
