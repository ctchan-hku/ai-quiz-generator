# Milestone v1.2: Model board & generation cost visibility

**Status:** SHIPPED 2026-05-05  
**Phases:** 10–11 (after v1.1 Phase 9)  
**Total plans:** 4 (10-01, 10-02, 11-01, 11-02)

## Overview

Backend exposes **pricing** on **`GET /api/models`** and **estimated `cost_usd`** on successful **`POST /api/generate/quiz`** and **`POST /api/generate/question`**. Frontend replaces the model dropdown with a **price-aware model board** (sort asc/desc), adds **Stop** for in-flight generation/refine, and surfaces **USD cost** on review, clipboard export, and **export journal** (schema v2). Follow-up quick work aligned generate routes with **client disconnect** cancellation (HTTP 499).

**Artifacts:** [v1.2-REQUIREMENTS.md](v1.2-REQUIREMENTS.md) · Phase folders under `.planning/phases/` (10-*, 11-*) · UAT: `10-UAT.md`, `11-UAT.md` (complete).

### Phase details

#### Phase 10: Models API pricing + generate cost fields

**Goal:** Backend exposes comparable prices per model and returns a defensible **USD estimate** per successful generation call.

**Depends on:** v1.1 complete  

**Requirements:** MOD-03, MOD-04, API-COST-01, API-COST-02  

**Success criteria:**

1. `GET /api/models` documents and returns pricing fields for each listed model (or explicit absence) consistent with deployment config.
2. Quiz generate response schema includes **`cost_usd`** populated on success from completion usage.
3. Question regenerate response includes the same cost field on success.
4. Automated tests cover schema/parsing; invalid models still **422**.

#### Phase 11: Model board, sort, stop, cost in UI

**Goal:** Users compare models by price, cancel stuck jobs, and see **cost + model** after generation and in the summary.

**Depends on:** Phase 10  

**Requirements:** FE-MB-01, FE-MB-02, FE-MB-03, FE-GEN-01, FE-COST-01, FE-COST-02  

**Success criteria:**

1. Model board loads from **`GET /api/models`** and displays prices; user picks one model for subsequent calls.
2. Toggle or control sorts by price ascending and descending.
3. **Stop** cancels the active request and leaves existing quiz data intact when aborting a redundant call.
4. Post-success UI and quiz summary show **USD cost** next to **model** text.

## Milestone summary

**Key decisions**

- Explicit **`price`** on env rows blocks overwrite by reference JSON; missing price merges from **`poe_ai_models.json`** when ids match.
- Question endpoint wrapper **`{ question, cost_usd }`**; frontend unwraps **`question`** for MCQ typing.
- Export journal **schema v2** with **`cost_usd`** per record; older localStorage journals cleared on load.
- Client **AbortSignal** per lane; backend **cancel on client disconnect** races LLM work with **`Request.is_disconnected()`** (HTTP 499).
