# Coding Start

- Brainstorm and get design approval before writing any code — follow `.agents/skills/brainstorming/SKILL.md`.
- Apply clean-code principles from `.cursor/rules/clean-code/` before coding.
- Keep changes minimal and targeted — follow `.agents/skills/karpathy-guidelines/SKILL.md`.
- Run `npm run lint:fix` after every code change.
- Do not add comments to code unless explicitly requested.
- Do not create files, documents, or summaries (e.g. changelogs, READMEs, analysis docs) unless explicitly requested.
