# Standup

Generates a concise daily standup update based on industry-standard practices.

## Execution

When executed, gather context on the user's recent work and current tasks, then format a standup report using the standard three-question structure.

## Output Format

Follow this exact structure for the standup report:

### 1. What did you accomplish yesterday?

- List completed tasks, merged PRs, or closed issues from the previous workday.
- Focus on outcomes and value delivered.
- Keep entries brief and to the point.

### 2. What will you be working on today?

- Outline the specific tasks planned for today.
- Highlight any priorities or time-sensitive deliverables.
- Note any tasks that involve collaboration or dependencies with others.

### 3. Are there any blockers in your way?

- List technical or organizational issues preventing progress.
- Specify what is needed to resolve the blocker (e.g., waiting on a review, missing assets).
- State "None" if there are no current impediments.

## Guidelines

- **Conciseness**: Keep updates brief; the goal is team alignment, not an exhaustive log.
- **Clarity**: Use bullet points and active voice for easy scannability.
- **Problem-Solving**: Do not solve blockers in the update; merely highlight them for separate follow-up.
